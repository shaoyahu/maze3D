迷宫的视觉风格，你更想要哪种？

这只是定基调。MVP 阶段所有风格都能做；不同风格只是材质/光照/色调不同。

[石墙 PBR 贴图]
[暖色点光源]
[正常亮度的走廊]

A · 写实/经典 FPS

带纹理的石墙/砖墙，普通亮度，温馨一点。像老式 Doom/Wolfenstein 的现代版。

[纯色平面墙壁]
[无纹理 / 简单几何]
[明亮、扁平色调]

B · Low-Poly / 风格化

几何感强、纯色面块，明亮友好。参考 Monument Valley 或 Roblox 那种质感。

[浓雾 / 视线短]
[手电筒式光源]
[冷色、阴森]

C · 黑暗 / 紧张 / 恐怖

视线短、强雾、阴影浓厚，配合后续怪物的紧张感会很好。FPS + horror 路线。

[发光边线 / 霓虹色墙]
[暗色基底]
[赛博朋克]

D · 赛博 / 霓虹

黑底霓虹色发光墙，赛博朋克调子。视觉冲击强，但和"老式恐怖"反差大。

选完在终端告诉我 (A/B/C/D)。也欢迎描述混合风格（比如 A 基础 + C 的氛围）。
