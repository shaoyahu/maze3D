## §8 跨切关注

1. **P2-13 测试覆盖广度**:EditorLeftPanel 8 case 覆盖了 empty / 渲染 / newLevel / newFolder / 点击 load / current 高亮 / delete level / delete folder(级联),但**右菜单的 rename / moveTo 完全没测**(见 M-2)。`levelStore.folders.test.ts` 在 store 层面测了 createFolder / renameFolder / moveLevel / moveFolder — 所以 store 是 OK 的;但 UI 层的"右键菜单触发 → prompt → store"路径无 pin。下一轮 P-13 触到这一路径的回归 CI 抓不到。
2. **act() 警告的来源**:`tests/component/editor/EditorStatusBar.test.tsx:55-87` `vi.useFakeTimers()` + 立即 `useEditorStore.setState` + `rerender` 的组合会触发 React 18 内部 setState 警告(因为 setState 不在 act() 包裹内)。**14/14 全过**,但若改 React 18 → 19 可能塌方。建议把 `setState` 包到 `act()` 里:
   ```ts
   act(() => { useEditorStore.setState({ dirty: true }); });
   rerender(<EditorStatusBar />);
   ```
3. **测试套件内 `makeMaze` 工厂函数至少 4 份重复**:`EditorLeftPanel` / `EditorStatusBar` / `levelStore.folders` / 原 `EditorLeftDrawer`(已删)各自维护一份。`a11y.test.tsx` 又有 resetEditor 自己的版本。**F-M-1** 长期未清理,本次 P2-13 增量代码继续推高重复。
4. **e2e skip 8 处的根因分解**:
   - 5 个 `page.clock + rAF` 不兼容:`survive.spec.ts:18` / `time-trial.spec.ts:12,38` / `pause-resume.spec.ts:39` / `enemies.spec.ts:26,41`

   - 1 个删除入口已搬到编辑器:`levelSelect` 对应 e2e 在 P2-13 已删(原 11 处含)
   - 1 个 internal 倒计时测试(`survive-branching` 0 命中)— 不重复
5. **`EditorStatusBar.test.tsx` 末尾**有 2 个 `afterEach` 重复(line 60-62 + 68-70,内容完全一样),可能是合并冲突遗留。功能上无害(`vi.useRealTimers()` 调两次),但代码异味。**F-L-2.5** 候选 — 见 §4。
