## Confirmed Findings

### FCR-M-2: `Dropdown.commit(activeIndex)` 陈旧闭包
- **File**: [src/ui/components/Dropdown.tsx:373](../../ui/components/Dropdown.tsx#L373)
- **Problem**: 
  ```ts
  onClick={() => { setActiveIndex(i); commit(activeIndex); }}
  ```
  `commit` 闭包捕获的是**上一次渲染**的 `activeIndex`,`setActiveIndex` 只更新下一帧。如果用户点击 disabled 项(被 guard 跳过 set),`commit(activeIndex)` 仍用旧 index——目前被 disabled guard 偶然兜底,但 `commit(i)` 直接传点击 index 才是正确写法。
- **Fix**: `onClick={() => commit(i)}` (再决定是否 `setActiveIndex`)。

### FCR-L-5: WinOverlay / GameOverOverlay / PauseOverlay 的 RAF 无 cleanup
- **Files**: 
  - [src/ui/WinOverlay.tsx:134-138](../../ui/WinOverlay.tsx#L134-L138)
  - [src/ui/GameOverOverlay.tsx:40-43](../../ui/GameOverOverlay.tsx#L40-L43)
  - [src/ui/PauseOverlay.tsx:28-31](../../ui/PauseOverlay.tsx#L28-L31)
- **Problem**: `useEffect` 内 `window.requestAnimationFrame(...)` 设置 `entered = true`,无 `return () => window.cancelAnimationFrame(id)`。如果组件在动画期间 unmount(rapid pause→menu),callback 在已 unmount 组件上 setState,React 18 会警告 "Can't perform a state update on an unmounted component"。
- **Fix**: 
  ```ts
  useEffect(() => {
    if (!open) return;
    const id = window.requestAnimationFrame(() => setEntered(true));
    return () => window.cancelAnimationFrame(id);
  }, [open]);
  ```

### FCR-L-6: `StatTile` / `ControlHints` / `MapHint` 缺 `React.memo`
- **Files**: [src/ui/WinOverlay.tsx:129-164](../../ui/WinOverlay.tsx#L129-L164) · [src/ui/HUD.tsx:3-40](../../ui/HUD.tsx#L3-L40)
- **Problem**: 父组件(WIN/HUD)订阅多 store 字段,频繁 re-render;`StatTile`(3 个实例)/ `ControlHints` / `MapHint` 自身 props stable,缺 memo 每次重渲染都跑一遍 reconciliation。`StatTile` 内部还有 stagger 入场动画 `delayMs`,会被无意义重置。
- **Fix**: 加 `export const StatTile = React.memo(function StatTile(...) {...})`,需 props 引用稳定。
