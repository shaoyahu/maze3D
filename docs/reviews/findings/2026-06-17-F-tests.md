## §2 CRITICAL

### C-1: `validateMaze` 静默吞字段,测试断言不充分

- **文件**: `tests/unit/maze/levels.test.ts:54-70` + `src/maze/JsonMazeProvider.ts:48-247`
- **影响**:4 个内置教学关卡 JSON 全部带 P2-11 字段(`i18n` / `tutorialSteps` / `hideMinimap` / `rules.enemyAggression` / `rules.requireAllPickups`)。`validateMaze` 读 `raw` 时只赋值它识别的字段,其余字段直接丢弃。`levels.test.ts` 唯一字段相关断言是 `data!.id === id`,**完全没断言"经过 validator 后所有 P2-11 字段都被保留"**。结果:959/1/0 测试全过 + 教学关卡的 P2-11 字段全部不存在于运行时数据。
- **复现**:
  ```ts
  // 在 tests/unit/maze/levels.test.ts 加:
  it('preserves P2-11 fields through validateMaze', () => {
    for (const { id, raw } of collectLevels()) {
      const data = validateMaze(raw, id);
      expect(data).toHaveProperty('i18n');          // 4/4 内置关卡
      expect(data).toHaveProperty('tutorialSteps'); // 哨兵回廊有
      expect(data).toHaveProperty('hideMinimap');   // teaching-02 有
      expect(data.rules).toHaveProperty('enemyAggression'); // teaching-03 有
    }
  });
  ```
  跑 `npx vitest run tests/unit/maze/levels.test.ts` → 4 个 expect 全部失败(因 validator 丢失字段)
- **修复**:
  1. **测试侧**:加上述断言 + 反向 case(把 P2-11 字段从 raw 里删掉,断言 validator 报错或默认化)
  2. **代码侧**:在 `validateMaze` 里把白名单外的字段也透传(或显式列白名单并对未列字段报错)
- **F-tag**: `F-2026-06-17-F-CRITICAL-1`(配套 `D-CRITICAL-1`)
